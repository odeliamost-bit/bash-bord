# Eerst doen (op de laptop van je broer)

Ik heb deze stappen niet zelf op jullie laptop getest. Loopt iets vast? Vraag het gerust.

## 1. 💳 Claude-abonnement
Claude Code werkt met een **Pro- of Max-abonnement** op claude.ai. Log in met jouw account.

## 2. 🤖 Claude Code installeren
Makkelijkst: de **Claude desktop-app** (Mac of Windows) van claude.ai/download. Daarin zit Claude Code.

Liever in de terminal?
- Mac / Linux: `curl -fsSL https://claude.ai/install.sh | bash`
- Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
  (op Windows ook **Git for Windows** installeren)

## 3. 📱 Android Studio installeren
Gratis, van developer.android.com/studio. Daar zit alles in om een Android-app te maken (Java, Android SDK).
Open het één keer en laat het de eerste downloads afmaken (duurt even).

## 4. 🔌 Telefoon klaarzetten
Op de Nothing Phone:
1. Instellingen › Over telefoon › tik **7 keer** op "Buildnummer".
2. Instellingen › Systeem › Ontwikkelaarsopties › zet **USB-foutopsporing** aan.
3. Telefoon met een USB-kabel aan de laptop. Tik "Toestaan".

## 5. 🐙 GitHub (aanrader, mag later)
- Maak een gratis account op github.com (als je dat nog niet hebt).
- Maak een **private** repository, bijvoorbeeld `mijn-dashboard`.
- Zo staat je werk veilig online. Claude Code kan je helpen het te koppelen.

## 6. 📁 Map maken en starten
1. Pak `dashboard-start.zip` uit in een nieuwe map, bijvoorbeeld `mijn-dashboard`.
2. Open die map in Claude Code (desktop-app: kies de map; terminal: `cd mijn-dashboard` en dan `claude`).
3. Plak de tekst uit **START-PROMPT.txt**.
4. Claude maakt een plan en vraagt of het mag beginnen. ✅
